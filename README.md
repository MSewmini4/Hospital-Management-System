# Smart Hospital Patient & Resource Allocation System

A C-based console application for managing hospital patients, wards, beds, priorities, waiting times, and billing.

## Features

* Patient registration
* Specialty and urgency selection
* Ward and bed allocation
* Patient priority sorting
* Waiting time calculation
* Billing and discounts
* Bed occupancy report
* Save and load patient data

## Files

* main.c – Main menu and program control
* hospital.c – Patient, bed, and billing functions
* hospital.h – Declarations and constants
* reports.c – Reports
* fileio.c – File handling
